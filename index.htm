About Akshat Network Hub

Akshat Network Hub is a digital portfolio and project showcase created to bring my web development work, academic journey, learning resources, and experiments together in one place.

I'm Akshat Prasad, a Bachelor of Computer Applications (BCA) student associated with Maharshi Dayanand University (MDU), Rohtak. This hub documents my progress as I learn, build, and improve practical technology solutions.

  • Project links and professional profiles in one place.
  • Responsive interface designed for mobile and desktop.
  • Learning resources and tools for students and developers.
  • Semantic structure and metadata to support discoverability.
